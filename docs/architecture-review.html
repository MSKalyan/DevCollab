Problem: /auth/me is re-fetched in 3 places, and the 401 interceptor excludes /auth/me from its retry queue — an expired access token on reload logs the user out despite a valid refresh cookie.

Solution: make useAuth the single owner of user state, fix the interceptor to retry /auth/me (guard against a refresh loop), and have adminRoute/EditProfile/ProjectList consume context.

  • Locality: user state lives in one module
  • Reload no longer logs users out
  • 3 re-fetches collapse to 1

Top recommendation

Candidate 1 — Close the User-model seam. It's the smallest move with the biggest locality win: every SQL statement lands behind a model interface, and the auth flows that carry the most recent churn become testable through a real seam.
